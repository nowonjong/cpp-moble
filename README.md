# 끗마릳기 — 난이도·연속 라운드 개정판

2026-09-10 추가 변경 사항입니다. 기존 규칙·점수·랭킹 기능은 유지하고 아래 기능만 수정했습니다.

- 게임 이름을 **끗마릳기**로 변경하고, 홈·게임·랭킹·규칙 화면을 하나의 디자인 체계로 전면 개편했습니다.
- 승리와 패배 때 전용 결과 카드, 화면 색상 변화, 파티클, 점수·플레이 기록 강조 애니메이션을 표시합니다.
- 최종 결과 화면에서 방금 플레이한 난이도의 상위 3명과 해당 난이도 안에서의 현재 플레이어 순위를 함께 표시합니다.
- 랭킹 화면은 **쉬움·보통·어려움** 탭으로 분리하며, 각 난이도 안에서 점수와 공동 등수를 다시 계산합니다.
- 컴퓨터가 단어를 잇지 못하면 최종 패배 효과보다 짧고 가벼운 **컴퓨터 KO +1,000점** 효과를 표시합니다.
- 시작 단어 계산을 한 번의 사전 순회로 줄이고 설정별 결과를 캐시해 게임 시작과 재도전 대기 시간을 단축했습니다.

- 컴퓨터가 단어를 잇지 못하면 **+1,000점**을 받고, 사용하지 않은 새 제시어로 다음 라운드를 계속합니다. 점수·이름·설정과 게임 전체의 사용 단어 기록은 유지하고 제출 기회만 초기화합니다.
- 한글 단어를 조합 중이어도 **Enter 한 번으로 조합 확정과 제출**을 함께 처리합니다. 제출 버튼도 그대로 사용할 수 있습니다.
- 난이도는 **쉬움·보통·어려움**입니다. 쉬움은 짧고 익숙하며 답이 많은 단어, 보통은 익숙하고 짧은 단어, 어려움은 이어갈 답이 적은 전략적인 단어를 고릅니다.
- 홈 화면의 난이도 선택을 세 버튼으로 정리하고, 게임 화면에 컴퓨터 패배 횟수와 누적 1,000점 보너스를 표시합니다.

## 2026-09-15 UI·프로필 보완

- 선택한 **E · 명예의 전당** 로고를 적용했습니다. 투명 PNG와 SVG 원본은 `data/branding/kkeut-maridegi-logo-horizontal.*` 및 `data/branding/kkeut-maridegi-icon.*`에 있습니다.
- 게임 화면을 플레이어와 컴퓨터의 대결 구도가 잘 보이는 UI로 다듬었습니다.
- 게임 중 **ESC 키 또는 일시정지 버튼**으로 멈출 수 있습니다. 점수·기회·사용 단어 등 진행 상태를 보존하며, 일시정지 중에는 컴퓨터 턴도 진행되지 않습니다.
- 사용자 프로필을 만들고 선택할 수 있습니다. 기존 랭킹 기록을 이름별로 집계해 프로필에 표시하며, 프로필 목록과 현재 선택은 `data/profiles.txt`에 저장합니다.
- 위 변경은 화면 구성과 일시정지·프로필 관리에 한정됩니다. 아래의 기존 게임 규칙, 점수, 난이도, 옵션, 연속 라운드 및 랭킹 기능은 그대로 유지됩니다.

## 실행

- 기존 SFML 창: `play.vbs` 또는 `play.cmd`. 홈에서 이름·난이도·세 가지 옵션을 선택합니다.
- 기능 확인용 콘솔: `play_console.cmd`. 같은 게임 코어를 사용합니다.
- 개발: `prototype.sln`은 SFML, `wordchain_console.vcxproj`는 콘솔입니다. VS2022 / v143 / x64 / C++17로 빌드합니다.
- 이번 변경은 두 실행본 모두 **Release 빌드**로 검증했습니다. Debug는 이번 최종 검사에 포함하지 않았습니다.

## 적용 기능

- 두음법칙은 항상 적용합니다. 원래 음절과 변환된 음절 모두 허용합니다. 예: 력→역, 년→연, 록→녹.
- 선택 옵션: **한방단어 허용 / 우리말만 / 쿵쿵따(정확히 세 음절)**.
- 옵션은 사람·AI·시작 단어·한방 판정에 함께 적용합니다.
- 정답 점수: **100 + 기회 보너스 + 음절 수×20**. 기회 보너스는 3/2/1회일 때 100/50/0점입니다.
- 매 턴 기회는 3번. 빈 입력은 기회를 쓰지 않고, 무효 제출은 기회 1번을 사용합니다.
- 컴퓨터가 막힐 때마다 +1,000점 후 새 라운드가 시작됩니다. 같은 게임에서는 이전 라운드의 단어도 다시 쓸 수 없으며, 사용하지 않은 시작 단어가 더는 없을 때만 최종 승리로 종료됩니다.
- 랭킹: **등수·이름·점수·난이도**. 점수 내림차순, 같은 점수는 공동 등수입니다.
- 힌트 기능과 설정을 제거했습니다.

기회 보너스의 구체적인 숫자는 우선 제안값으로 적용했습니다. 변경할 때는 `ScorePolicy.h`의 계산식을 수정하면 됩니다.

## 사전과 랭킹 파일

| 파일 | 역할 |
|---|---|
| `data/words.txt` | 기존 전체 사전. 내용을 유지했습니다. |
| `data/korean_words.txt` | 우리말 허용 목록. 전체 사전에도 등록된 434개가 현재 적용됩니다. |
| `data/rankings.txt` | 새 랭킹 데이터. 첫 게임 종료 시 생성됩니다. |
| `data/records.txt` | 이전 점수 체계의 전적. 보존하며 새 랭킹으로 가져오지 않습니다. |
| `data/profiles.txt` | 로컬 사용자 프로필 목록과 현재 선택. 첫 프로필 선택 시 생성됩니다. |
| `data/branding/` | E안 가로형 로고와 아이콘의 투명 PNG·SVG 자산. |

‘우리말만’은 우선 **외래어 제외·한자어 허용**으로 해석했습니다. 현재 전체 사전에는 어종 정보가 없어서 자동 판별하지 않고 별도 허용 목록을 사용합니다. 초기 목록은 전체 사전을 분류한 완성 데이터가 아닙니다. 우리말이어도 목록에 없으면 이 모드에서는 인정되지 않으므로 사전 담당자가 보강해 주세요.
