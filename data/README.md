# 사전·랭킹 파일

- `words.txt`: 전체 허용 사전 27,832개. 기존 파일 그대로입니다.
- `korean_words.txt`: ‘우리말만’ 모드의 초기 허용 목록. 현재 434개가 전체 사전과 일치합니다.
- 두 사전은 UTF-8, 한 줄에 한 단어입니다. 중복·잘못된 형식은 제외합니다.
- 우리말 목록의 단어도 전체 사전에 있어야 적용됩니다. 재실행하면 변경을 반영합니다.
- ‘우리말만’은 외래어 제외·한자어 허용으로 우선 정의했습니다. 단어 표기만으로 어종이나 품사를 자동 판별하지 않습니다.
- 우리말 목록은 전체 어휘를 분류한 완성 사전이 아닙니다. 팀원이 원본 출처·어종·품사를 확인하면서 보강해야 합니다.
- `rankings.txt`: 이름과 새 점수 체계의 V2 랭킹 기록. 첫 게임 종료 시 생성됩니다.
- `records.txt`: 이전 전적 파일. 새 랭킹에 사용하지 않고 보존합니다.

현재 기능·정책은 [변경 문서](../docs/기능변경_2026-09-10.md)를 참고하세요.
