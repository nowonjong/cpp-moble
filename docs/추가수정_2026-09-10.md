# 추가 수정 사항과 검증

## 컴퓨터 패배 뒤 계속하기

컴퓨터가 이어갈 단어를 찾지 못하면 게임을 끝내지 않고 1,000점을 더합니다. 같은 이름·난이도·옵션·누적 점수를 유지한 채 새 라운드를 시작합니다. 새 라운드는 단어 중복 이력과 제출 오류 횟수를 초기화하고, 현재 설정으로 실제 답할 수 있는 제시어를 다시 고릅니다.

게임은 사용자가 한 턴에 세 번 틀리거나 포기할 때 종료됩니다. 창을 닫아 중단하는 기존 처리와 랭킹 규칙도 유지합니다. 컴퓨터 패배 보너스는 `ScorePolicy::ComputerDefeatBonus` 상수입니다.

## Enter 한 번 제출

Windows 한글 IME가 Enter를 조합 확정에 먼저 사용하는 경우, 조합 종료 메시지가 끝난 뒤 같은 Enter를 제출 요청으로 전달합니다. 확정 글자가 입력창에 반영되기 전에 읽지 않도록 별도 사용자 메시지로 한 번 지연하고, 키 반복과 문자 메시지에서는 중복 제출하지 않습니다.

## 난이도

| 난이도 | 컴퓨터 선택 |
|---|---|
| 쉬움 | 우리말 기본 목록의 짧고 익숙한 단어를 우선하고, 사용자가 이어갈 후보가 많은 단어 선택 |
| 보통 | 우리말 기본 목록의 4음절 이하 단어를 우선해 무작위 선택 |
| 어려움 | 이어갈 후보 수가 가장 적은 전략적인 단어 선택 |

우리말만·한방단어·쿵쿵따·두음법칙·기회 및 기본 점수 계산은 기존 기능을 그대로 적용합니다. 세 난이도 모두 현재 옵션에 맞는 합법 단어만 사용합니다.

## 검증

- C++17 Release 빌드: 경고 없이 완료
- 코어 자동 검사: 16개 그룹 통과
- 실제 전체 사전 검사: 규칙 옵션 8조합과 세 난이도 사용, 시작·응답·종료·랭킹 저장 확인
- SFML 자동 검사: 화면, 입력 전달, 오류 기회 차감, AI 턴, 컴퓨터 패배 +1,000점, 1,430점 상태에서 새 라운드 지속, 종료 후 랭킹 저장 확인
- 화면 캡처로 홈의 세 난이도 버튼, 계속 진행 안내, 랭킹 레이아웃 확인

한글 IME 종류에 따라 메시지 순서가 달라질 수 있으므로 배포 PC에서는 첫 실행 시 실제 한글 조합으로 Enter 한 번 제출을 한 차례 확인하는 것을 권장합니다.
