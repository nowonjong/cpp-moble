# 2026-09-10 기능 변경 및 인수인계

## 완료한 범위

두음법칙 상시 적용, 세 가지 옵션, 기회·길이별 점수, 이름별 랭킹, 힌트 제거를 구현했습니다. 화면을 새로 디자인하지 않고 기존 SFML의 입력·버튼·표시를 새 기능에 연결했습니다. 콘솔에서도 같은 코어로 모든 기능을 확인할 수 있습니다.

## 이번에 적용한 정책

| 항목 | 기준 |
|---|---|
| 두음법칙 | 원래 음절 또는 초성 변환 음절 허용. 받침 유지. 역방향 변환 없음. |
| 한방단어 | 제출 단어 자신과 이미 쓴 단어를 제외하고, 두음·언어·길이 조건에 맞는 응답 단어가 없으면 한방. |
| 한방 금지 | 한방 제출은 무효이며 기회를 1번 사용. 사람·AI가 같은 판정 사용. |
| 한방 판정의 다음 후보 | 다음 후보의 언어·길이·중복·연결 조건만 확인. 한방 금지를 재귀적으로 검사하지 않음. |
| 우리말만 | 외래어 제외·한자어 허용으로 우선 적용. 별도 허용 사전 사용. |
| 쿵쿵따 | 시작 단어·사람·AI 모두 정확히 3음절. |
| 점수 | 기본 100 + 기회 보너스(3/2/1회: 100/50/0) + 음절 수×20. |
| 랭킹 | 완료한 각 게임을 한 줄로 기록. 같은 이름도 여러 판이면 여러 줄. |
| 동점 | 먼저 저장된 기록부터 표시, 공동 등수 1·1·3 방식. |
| 중단 | 기록 파일에는 저장하되 랭킹에서 제외. 포기는 패배로 완료되어 랭킹에 포함. |
| 이름 | 한글·영문·숫자·공백·밑줄, 1~12글자. 앞뒤 공백 제거. |
| 난이도 | 쉬움·보통·어려움. 쉬움과 보통은 익숙한 짧은 단어 우선, 어려움은 전략형. |
| 컴퓨터 패배 | +1,000점 후 사용 단어·기회를 초기화하고 새 제시어로 계속. |

기회별 추가 점수와 ‘우리말’의 범위는 사용자의 세부 확정 답변 없이 우선 적용한 값입니다. 변경 요청이 오면 이 두 기준을 먼저 수정하면 됩니다. 점수 정책에 시간·승리 보너스는 없습니다.

## 점수 예시

| 정답 길이 | 기회 3번일 때 | 기회 2번일 때 | 기회 1번일 때 |
|---|---:|---:|---:|
| 2음절 | 240 | 190 | 140 |
| 3음절 | 260 | 210 | 160 |
| 4음절 | 280 | 230 | 180 |

잘못된 제출은 점수를 주지 않습니다. 정답 처리 전에 남은 기회로 점수를 계산하며, 다음 사람 턴에 기회가 3번으로 돌아옵니다. UTF-8 바이트 수가 아니라 한글 음절 수로 계산합니다.

## 팀원별 주요 파일

| 담당 | 변경된 인터페이스·자료 |
|---|---|
| 1번 사전 | `Dictionary::loadKoreanWords`, `isKoreanWord`, `koreanSize`, `data/korean_words.txt` |
| 2번 규칙 | `allowedStarts`, `validate(..., settings)`, `wordAllowed`, `hasReply` |
| 3번 AI | 후보·선택·시작 단어 함수에 Settings 전달. 세 난이도에 같은 규칙 검사 기준 사용. |
| 4번 게임 | `startNewGame(settings, name, openingForTest)`, `GameState::lastAward`, `computerDefeats`, `ScorePolicy` |
| 5번 기록 | `GameRecord::name`, `RecordManager::rankings()`, `validName`, V2 파일 |
| 6번 연결 | `SfmlApplication`, `Application`, `ConsoleUI`, `wordchain_console.vcxproj` |

`Settings`는 difficulty / allowOneShot / koreanOnly / threeSyllables입니다. dueumEnabled·hintEnabled·requestHint와 HintSystem 파일을 제거했습니다.

## 파일 저장

새 파일은 `data/rankings.txt`이며, 첫 줄은 `WORDCHAIN_RANKING_V2`입니다.

```text
WORDCHAIN_RANKING_V2
"홍 길동" 480 EASY WIN 1 0 0
```

각 행은 이름·점수·난이도·결과·한방허용·우리말만·세글자 순서입니다. 화면에는 등수·이름·점수·난이도만 표시합니다. 잘못된 형식은 저장을 막고, 초기화 시 기존 파일을 백업합니다. 예전 `records.txt`는 이름도 없고 점수 체계가 달라 자동 변환하지 않고 보존했습니다.

## 사전 보강 범위

전체 사전 27,832개는 유지했습니다. 우리말 허용 목록은 초기 목록이며 현재 전체 사전과 겹치는 434개가 적용됩니다. 목록 밖 단어를 외래어라고 단정하는 방식이 아니라 **확인된 허용 목록에 없어서 제외**하는 방식입니다. 모드의 어휘 범위를 넓히려면 사전 담당자가 어종·품사·출처를 검토해 보강해야 합니다. 새 단어는 두 파일 모두에 있어야 우리말 모드에서 사용할 수 있습니다.
