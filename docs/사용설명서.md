# 끗마릳기 사용설명서

## 1. 실행과 새 게임

1. prototype 폴더의 play.cmd를 실행합니다.
2. 처음에는 쉬움 난이도, 힌트 OFF입니다.
3. 2번 메뉴에서 난이도와 힌트를 선택할 수 있습니다.
4. 1번 메뉴로 새 게임을 시작합니다.
5. 컴퓨터가 시작 단어를 제시하면 마지막 음절에 이어지는 단어를 입력합니다.

시작 단어는 사람이 이어갈 미사용 단어가 하나 이상인 후보에서 선택합니다. 한 판 중 설정은 바뀌지 않습니다.

## 2. 입력과 점수

- 게임 사전에 등록된 2~64음절 완성형 한글 단어를 사용합니다.
- 기본 사전은 일반 명사를 선정한 목록입니다.
- 앞 단어의 끝 음절과 다음 단어의 첫 음절이 정확히 같아야 합니다.
- 같은 단어는 한 판에 한 번만 사용할 수 있습니다.
- 정답마다 10점입니다. 컴퓨터가 낸 단어로 사람 점수가 오르지는 않습니다.
- 한글 형식·사전·중복·연결 검사를 통과하지 못하면 제출 기회를 한 번 사용합니다.
- 각 사람 턴마다 총 3회 기회가 있으며, 다음 사람 턴에 다시 3회가 됩니다.
- 빈 입력은 재입력만 안내합니다. 앞뒤 공백은 제거하고 내부 공백은 거절합니다.
- 두음법칙을 적용하지 않으므로 리→이 같은 변환은 허용하지 않습니다.
- 게임 도중 한방 단어는 허용합니다.

## 3. 승패와 종료

| 상황 | 처리 |
|---|---|
| 컴퓨터가 낼 미사용 후보가 없음 | 사람 승리 |
| 사람이 낼 미사용 후보가 없음 | 사람 패배 |
| 이번 사람 턴의 세 번째 오답 | 사람 패배 |
| 단어 입력에서 quit 입력 | 포기 패배 |
| 진행 중 입력 종료(EOF) | 중단 |
| 메인 메뉴에서 0 또는 EOF | 프로그램 종료, 새 게임 기록 없음 |

Windows 콘솔에서는 Ctrl+Z를 누르고 Enter를 입력하면 EOF로 중단할 수 있습니다. 창을 강제로 닫는 것은 정상 종료 저장을 보장하지 않으므로 quit 또는 메뉴 종료를 사용하세요.

중단한 판도 기록에는 남지만 승패와 최고 점수에서는 제외합니다.

## 4. 난이도와 힌트

쉬움 AI는 합법적인 미사용 후보 중 무작위로 선택합니다. 보통 AI는 각 후보를 낸 뒤 사람이 낼 수 있는 단어 수를 계산해 가장 적은 후보를 고릅니다. 동점은 무작위입니다. 항상 승리를 보장하는 전략은 아닙니다.

힌트를 켠 게임에서 hint를 입력하면 후보 하나의 첫 음절과 길이를 알려줍니다.

- 게임당 최대 3회, 한 번에 5점
- 5점 미만이면 사용할 수 없음
- 힌트를 실제로 만들었을 때만 점수·횟수 차감
- 턴과 오입력 횟수는 유지
- 전체 단어는 표시하지 않음

첫 음절은 진행 화면에도 표시되므로 이 힌트는 주로 후보 단어의 길이를 좁히는 용도입니다.

## 5. 전적과 파일 오류

3번 메뉴에서 승리·패배·중단 횟수, 최고 점수와 최근 10판을 확인합니다. 최고 점수는 난이도를 합친 완료 게임 기준입니다.

기록 파일이 처음부터 없으면 새 기록으로 시작합니다. 손상된 기록이나 읽기 실패가 있으면 다음을 선택합니다.

- 백업 후 초기화: 기존 파일을 records.txt.bak.번호로 보관한 뒤 빈 기록을 생성합니다.
- 저장 없이 계속: 기존 파일을 보존하고 이번 실행의 저장을 중지합니다.
- 종료

저장에 실패해도 승패와 최종 점수는 결과 화면에 표시합니다. 실패한 결과는 전적 파일과 기록 통계에 추가되지 않습니다. 자동 저장 재시도는 하지 않습니다.

설정 메뉴의 마지막 선택은 다음 프로그램 실행에 자동 복원하지 않습니다. 각 판에서 실제로 사용한 설정은 기록에 보존합니다.

## 6. 사전 교체와 실행 경로

data/words.txt를 UTF-8로 저장하고 한 줄에 한 단어를 적습니다. 프로그램을 재실행하면 새 사전을 읽습니다.

BOM, CRLF, 앞뒤 공백, 빈 줄, 중복을 처리합니다. 손상된 UTF-8이나 허용하지 않는 문자·길이의 행은 제외하고 개수를 안내합니다. 실제 명사인지의 확인은 사전 작성자가 맡습니다.

5번 메뉴에서 실제 사용 중인 사전·기록 경로와 시작 가능한 단어 수를 확인할 수 있습니다.

다른 사전 폴더를 사용하려면 다음처럼 실행합니다.

~~~bat
bin\Release\prototype.exe --data-dir "사용할 데이터 폴더"
~~~

지정한 폴더 안의 words.txt를 읽고 같은 폴더의 records.txt에 기록합니다. 경로를 생략하면 현재 작업 폴더와 실행 파일 주변의 data 폴더를 확인합니다. play.cmd는 현재 작업 폴더를 prototype으로 맞춥니다.
